🔐 Supabase Setup Guide

Настройка системы аккаунтов за 10 минут

1
Создайте проект Supabase
  1. Перейдите на supabase.com
  2. Нажмите "Start your project"
  3. Войдите через GitHub или создайте аккаунт
  4. Заполните форму создания проекта:
    • Name: itop-desktop-clone
    • Database Password: [Запомните этот пароль!]
    • Region: Выберите ближайший к вам
  5. Нажмите "Create new project"
⏱ Проект создаётся 2-5 минут. Дождитесь завершения!
2
Получите API ключи
  1. В проекте перейдите в Settings (шестерёнка внизу слева)
  2. Выберите API
  3. Скопируйте два значения:
    • Project URL: https://xxxxx.supabase.co
    • anon/public key: eyJhbGc... (длинная строка)
✅ Конфигурация сохранена в supabase-client.js
3
Создайте таблицы базы данных
  1. В Supabase перейдите в SQL Editor (в левой панели)
  2. Нажмите "New query"
  3. Скопируйте и выполните следующий SQL скрипт:
-- Таблица профилей пользователей create table profiles ( id uuid references auth.users on delete cascade primary key, email text unique not null, full_name text, avatar_url text, account_type text default 'free' check (account_type in ('free', 'pro')), license_key text unique, license_expires_at timestamptz, created_at timestamptz default now(), updated_at timestamptz default now() ); -- Таблица приватных боксов create table private_boxes ( id uuid default uuid_generate_v4() primary key, user_id uuid references profiles(id) on delete cascade not null, name text not null, password_hash text not null, recovery_email text, encrypted_data jsonb, created_at timestamptz default now(), updated_at timestamptz default now(), unique(user_id) ); -- Таблица снимков рабочего стола create table desktop_snapshots ( id uuid default uuid_generate_v4() primary key, user_id uuid references profiles(id) on delete cascade not null, name text not null, description text, snapshot_data jsonb not null, created_at timestamptz default now() ); -- Таблица лицензионных ключей create table license_keys ( id uuid default uuid_generate_v4() primary key, key text unique not null, type text default 'pro' check (type in ('pro', 'trial')), duration_days integer default 365, is_used boolean default false, used_by uuid references profiles(id), created_at timestamptz default now(), activated_at timestamptz );
4
Настройте RLS (Row Level Security)
  1. В том же SQL Editor выполните второй скрипт:
-- Включить RLS для всех таблиц alter table profiles enable row level security; alter table private_boxes enable row level security; alter table desktop_snapshots enable row level security; alter table license_keys enable row level security; -- Policies для profiles create policy "Users can view own profile" on profiles for select using (auth.uid() = id); create policy "Users can update own profile" on profiles for update using (auth.uid() = id); create policy "Users can insert own profile" on profiles for insert with check (auth.uid() = id); -- Policies для private_boxes create policy "Users can view own private box" on private_boxes for select using (auth.uid() = user_id); create policy "Users can create own private box" on private_boxes for insert with check (auth.uid() = user_id); create policy "Users can update own private box" on private_boxes for update using (auth.uid() = user_id); create policy "Users can delete own private box" on private_boxes for delete using (auth.uid() = user_id); -- Policies для desktop_snapshots create policy "Users can view own snapshots" on desktop_snapshots for select using (auth.uid() = user_id); create policy "Users can manage own snapshots" on desktop_snapshots for all using (auth.uid() = user_id); -- Policies для license_keys create policy "Users can view license keys" on license_keys for select using (true); create policy "Users can update used license keys" on license_keys for update using (true);
5
Создайте тестовый лицензионный ключ
  1. В SQL Editor выполните:
-- Создать Pro лицензию на 1 год insert into license_keys (key, type, duration_days) values ('ITOP-PRO-ABCDE-12345-FGHIJ', 'pro', 365), ('ITOP-PRO-TEST11-11111-TEST1', 'pro', 365), ('ITOP-PRO-TRIAL-00001-TRIAL', 'trial', 14);
6
Проверка готовности

Отметьте выполненные шаги:

  • Supabase проект создан
  • API ключи скопированы
  • Конфигурация сохранена в supabase-client.js
  • Таблицы созданы (4 таблицы)
  • RLS policies настроены
  • Лицензионные ключи созданы
  • Зависимости установлены (npm install)
