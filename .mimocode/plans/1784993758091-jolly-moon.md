# План стилизации меню

**Цель:** Улучшить визуальную стилизацию контекстного меню боксов и навигационного меню.

## Анализ текущего состояния

### Текущая стилизация
- Контекстное меню: базовый glass-эффект, простая анимация
- Навигационное меню: градиенты, hover-эффекты
- Подменю: базовое отображение

### Проблемы
1. Контекстное меню выглядит плоским
2. Нет эффекта свечения (glow)
3. Подменю открывается без анимации
4. Нет разделителей с градиентом
5. Hover-эффекты простые

## Конкретные изменения

### styles.css - Контекстное меню

```css
.context-menu {
  background: rgba(22, 27, 40, 0.95);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.1);
  border-radius: 12px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.5),
              0 0 0 1px rgba(168, 85, 247, 0.1);
}

.context-menu-item:hover {
  background: linear-gradient(135deg, rgba(168, 85, 247, 0.1), rgba(236, 72, 153, 0.1));
  box-shadow: inset 0 0 20px rgba(168, 85, 247, 0.1);
}
```
