## Настройка проекта

1. Создать проект на supabase.com
2. Выполнить SQL скрипты из `desktop-app/supabase-tables.sql`
3. Настроить RLS политики из `supabase-rls.sql`
4. Получить URL и Anon Key из Settings → API
