# Admin Panel - Страницы

**Статус:** ✅ Готово

---

## Dashboard

- Статистика: количество пользователей, Pro пользователей, лицензий
- Графики регистраций (Recharts)
- Последние активации

## Users

- Список всех пользователей
- Поиск и фильтрация
- Изменение ролей (user/admin/superadmin)
- Удаление пользователей

## Licenses

- Генерация ключей (пакетно)
- Список всех ключей
- Активация/деактивация
- Фильтр по типу (pro/trial)

## Settings

- Профиль администратора
- Настройки безопасности
- Информация о системе
