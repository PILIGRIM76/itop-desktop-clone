# Telegram Bot - Команды

**Статус:** ✅ 80%

---

## Команды

| Команда | Описание | Доступ |
|---------|----------|--------|
| `/start` | Приветствие | Все |
| `/stats` | Статистика системы | Admin |
| `/key <type> [count]` | Генерация ключей | Admin |
| `/user <email>` | Поиск пользователя | Admin |
| `/check <key>` | Проверка ключа | Все |
| `/activate <key>` | Активация ключа | Все |
| `/revoke <key>` | Отзыв ключа | Superadmin |

## Типы ключей

- `pro` — годовая лицензия (365 дней)
- `trial` — пробная (14 дней)

## Примеры

```
/key pro 5        — сгенерировать 5 Pro ключей
/key trial 10     — сгенерировать 10 Trial ключей
/user user@example.com — найти пользователя
/check ITOP-PRO-ABCDE-12345-FGHIJ — проверить ключ
```

## Безопасность

- Whitelist Chat ID для администраторов
- Проверка роли через Supabase `is_admin()`
- Логирование всех команд
