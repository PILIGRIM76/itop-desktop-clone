# Wallpapers (Обои)

**Статус:** ⚠️ 85%  
**Файлы:** `wallpaper-manager.js`, `wallpaper-creator.js`

---

## Типы обоев

| Тип | Описание | Статус |
|-----|----------|--------|
| Live | Видео обои | ✅ |
| Static | Изображения | ✅ |
| Playlist | Плейлист (Single Loop, Shuffle, Order) | ✅ |
| Created | Созданные в Wallpaper Creator | ✅ |

## Wallpaper Creator

Создание обоев с эффектами:
- Particle effects (частицы)
- Filters (фильтры)
- Cursor effects (эффекты курсора)

## Недостающий функционал

1. **Lock Screen** — применение обоев на экран блокировки Windows ❌
2. **My Wallpapers UI** — полный интерфейс управления ⚠️

## IPC Каналы

- `set-wallpaper` — установка обоев
- `get-wallpapers` — список обоев
- `create-wallpaper` — создание нового
