## Описание

Собственная реализация меню Пуск для замены системного. Полнофункциональный интерфейс для запуска приложений, поиска и управления системой.

## Требования

### Functional
- [x] Поиск приложений/файлов
- [x] Список установленных программ (чтение из ProgramData/Start Menu)
- [x] Pin/Unpin приложений
- [x] Power options (Sleep, Shutdown, Restart, Lock)
- [x] Пользовательская папка (Documents, Pictures, Downloads, Music, Videos)
- [x] Keyboard navigation (стрелки, Enter, Esc)
- [x] Быстрый доступ к настройкам

### Non-functional
- [x] Плавная анимация открытия/закрытия
- [x] Тёмная тема по умолчанию
- [x] Поддержка Windows 10/11
- [ ] Производительность < 100ms на открытие (тестировать)

## Что реализовано

1. **app-list-manager.js** - Сканирование ярлыков из Start Menu папок Windows
2. **start-menu.html** - Полная разметка с тёмной темой
3. **start-menu.js** - Логика поиска, pin, power options
4. **preload.js** - 10 IPC каналов для Start Menu
5. **main.js** - Окно Start Menu + все IPC обработчики
