# Boxes (Боксы)

**Статус:** ✅ 100%  
**Файлы:** `main.js`, `renderer/app.js`, `renderer/box.html`

---

## Описание

Боксы — основной функционал приложения. Позволяют организовать файлы рабочего стола в группы по типам, назначению или правилам.

## Функционал

### Создание боксов
- Ручное создание с выбором типа
- Folder Portal (привязка к папке)
- Private Box (зашифрованный, PRO)

### Drag and Drop ✅
- Перетаскивание файлов из Windows Explorer
- Перетаскивание файлов между боксами
- Визуальная обратная связь (подсветка, счетчик файлов)
- Уведомления о результате добавления

### Удаление файлов ✅
- Кнопка удаления при наведении на файл
- Подтверждение перед удалением
- Уведомление об успешном удалении
- Автоматическое обновление списка

### Переименование файлов ✅
- Кнопка переименования при наведении
- Inline-редактирование (input вместо текста)
- Enter для подтверждения
- Escape для отмены
- Проверка на дубликаты имен
- Уведомление о результате

### Настройка (вкладки)
| Вкладка | Функции |
|---------|---------|
| Appearance | Цвета, шрифты, прозрачность, скругления |
| Organization | Правила автосортировки, приоритеты, фильтрация |
| Quick Actions | Клики, горячие клавиши, сортировка |
| Layout | Позиции, сетка, мульти-монитор |
| Snapshot | Создание, восстановление, импорт/экспорт |

### Tab Mode
Объединение боксов в табы для экономии места.

### Контекстное меню (правый клик)
- Rename — переименование
- Change Icon — смена иконки
- Duplicate — дублирование
- Merge into Tab — объединение с другим боксом
- Delete — удаление

## IPC Каналы

- `create-box` — создание нового бокса
- `update-box` — обновление настроек
- `delete-box` — удаление бокса
- `get-boxes` — получение списка боксов
- `organize-desktop` — запуск автосортировки
- `add-items-to-box` — добавление файлов (drag and drop)
- `remove-item-from-box` — удаление файла из бокса
- `rename-file` — переименование файла

## Правила организации

```javascript
// Пример правила
{
  name: "Изображения",
  pattern: "*.jpg|*.png|*.gif",
  targetBox: "Фото",
  priority: 1
}
```
