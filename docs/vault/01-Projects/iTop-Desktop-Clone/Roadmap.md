# Доработка приложения до уровня iTop Easy Desktop V4

**Статус:** В работе
**Обновлено:** 26 июля 2026

---

## Цель

Довести функционал нашего клона до уровня оригинального iTop Easy Desktop V4, добавив недостающие ключевые фичи.

---

## P0 - Критичные (эта неделя)

### 1. Folder Portal
- Быстрый доступ к содержимому любой папки с рабочего стола
- Как мини-проводник встроен в рабочий интерфейс
- Реализация: новый тип бокса "Folder Portal"

### 2. Double-click to hide all
- Двойной клик по рабочему столу скрывает все боксы
- Повторный клик показывает
- Реализация: IPC handler для double-click на desktop

### 3. New file detection
- Красная метка на новых файлах, не добавленных в бокс
- Отслеживание файловой системы через fs.watch
- Реализация: badge на боксе с количеством новых файлов

### 4. Desktop Icons styles
- Смена иконок Windows на стиль Apple или Samsung
- Пакеты иконок (.ico файлы)
- Реализация: модуль замены иконок через реестр Windows

---

## P1 - Важные (следующая неделя)

### 5. PawPal - Цифровой питомец
- Милый кот на рабочем столе
- Интерактивность: кормить, играть, болтать
- Обычный/тихий режим
- Панель питомца
- Скрыть/показать

### 6. Lock Screen wallpapers
- Применение статичных обоев на экран блокировки Windows
- Через Windows API или реестр

### 7. Mouse Effects в Wallpaper Creator
- Эффекты курсора при создании обоев
- Частицы, след, свечение

## P2 - Улучшения (позже)

### 8. Real Taskbar hiding
- Скрытие системной панели задач через WinAPI
- FindWindow("Shell_TrayWnd") → ShowWindow(SW_HIDE)

### 9. Real Cursor replacement
- Замена системного курсора через WinAPI
- SetSystemCursor()

### 10. Wallpaper catalog
- Каталог 22,000+ обоев
- API для скачивания
- CDN для хранения
