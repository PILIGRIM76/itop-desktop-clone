## Что нужно доработать (Приоритет)

### P0 - Критичные (делают приложение конкурентоспособным)
1. **Folder Portal** - быстрый доступ к папке с рабочего стола
2. **Double-click to hide all** - скрытие всех боксов двойным кликом
3. **New file detection** - красная метка на новых файлах
4. **Desktop Icons styles** - смена иконок Windows на Apple/Samsung

### P1 - Важные
5. **PawPal** - цифровой питомец (новая фича iTop V4)
6. **Lock Screen wallpapers** - применение обоев на экран блокировки
7. **Mouse Effects** - эффекты курсора в Wallpaper Creator
8. **Publish wallpapers** - публикация созданных обоев

### P2 - Улучшения
9. **Wallpaper catalog** - каталог 22,000+ обоев (нужен API/CDN)
10. **Real Taskbar hiding** - реальное скрытие системной панели
11. **Real Cursor replacement** - реальная замена системного курсора
